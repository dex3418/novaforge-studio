Paste a script, choose what to make, press Start. Rate each result so the next one gets better.
One-time setup needed

No GitHub token found. In Termux run:

read -rsp "Paste token: " T; echo; printf 'GITHUB_TOKEN=%s\n' "$T" > ~/.novaforge-studio.env; chmod 600 ~/.novaforge-studio.env; unset T

Then stop the box (Ctrl+C) and start it again.

e.g. dex3418 uses your GitHub profile picture. Photos you commit to studio/assets/pictures/ are used automatically. Pick the Founder or Gallery template to build around them.
