# Bundled fonts (v27)

The workflow copies these into ~/.fonts instead of installing `fonts-noto-core` from the Ubuntu mirror on every run.
They are the exact files that package ships (Noto 20201225, JetBrains Mono 2.304), so renders look the same.
Licences: SIL Open Font License 1.1 (Noto, JetBrains Mono). Emoji (Noto Color Emoji) and DejaVu come with the runner image.
